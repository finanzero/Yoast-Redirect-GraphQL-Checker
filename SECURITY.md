# Security Policy

## Supported Versions

This plugin does not currently follow a versioned release schedule; the `main`
branch is the only supported version. Please always run the latest commit.

## Reporting a Vulnerability

Please do **not** open a public issue for security vulnerabilities.

Instead, use GitHub's [private vulnerability reporting](../../security/advisories/new)
for this repository (Security tab → "Report a vulnerability"). This opens a
private advisory visible only to the maintainers until a fix is available.

We'll acknowledge reports as soon as possible and keep you updated as we
investigate and resolve the issue.
